# A8 — проход по производительности и доступности

Замеры сделаны в браузере (Playwright) на локальном стенде 2026-09-08, роли:
гость, кандидат (User 50), шадхан (User 57), администратор (User 1).
Скриншоты «после» — в `docs/screens/` (1440×900, главная и регистрация ещё и 375×740).

## Что проверялось на каждом экране

| Проверка | Как | Порог |
|---|---|---|
| Ошибки в консоли | `browser_console_messages` | только `[SmartCaptcha] … localhost` (ключ виджета привязан к боевому домену) |
| Горизонтальная прокрутка | `documentElement.scrollWidth` vs `innerWidth` | scrollWidth ≤ ширины окна |
| Картинки без `alt` | запрос по DOM | 0 |
| Кнопки и ссылки без доступного имени | текст, `aria-label`, `title` | 0 (кроме ссылки студии из бандла) |
| Поля без подписи | `label[for]`, обёртка `<label>`, `aria-label` | 0 |
| Заголовок страницы | `<h1>` | ровно один |
| Ориентиры | `id="main"`, ссылка «к содержимому» | есть в макете |

## Что исправлено в этом проходе

- Имена у элементов-иконок: бургер и его крестик, логотипы в шапке и подвале,
  иконки соцсетей (YouTube, Instagram, Telegram), стрелки слайдеров, крестики
  модальных окон. Кнопкам добавлен `type="button"` — без него они отправляли
  форму, внутри которой оказывались.
- Подписи полей без видимого лейбла: формы «Задать вопрос», «Стать партнёром»,
  «Написать администратору», фильтр витрины, имена родных в мастере анкеты.
- Картинка-ссылка новости скрыта от экранного диктора (`aria-hidden`,
  `tabindex="-1"`): рядом стоит такая же ссылка-заголовок с текстом.
- Заголовки страниц: регистрация и консультант получили `<h1>`.

Проверки закреплены тестом `tests/a11y_test.py` (10 проверок), включая
совпадение правок в файлах-близнецах (`Template.html` = `Header` + `Footer`,
`Class.html` = части).

## Известное и осознанно не исправленное

- Ссылку студии-разработчика в подвал вставляет бандл (`a.develop_rbm`), в наших
  шаблонах её нет — два элемента без доступного имени на каждой публичной
  странице. Правится только пересборкой бандла, исходников которого нет.
- Ошибка `[SmartCaptcha] Widget with this key cannot be used in the host` на
  стенде — ключ виджета привязан к домену shiduh.org, на localhost не работает.
  На проде её нет.
- Chrome на `admin-ai.php` советует добавить скрытое поле имени пользователя
  рядом с полем ключа провайдера. Это не форма входа, автозаполнение там не
  нужно — оставлено как есть.
- Тёмная тема не делается (решение этапа: `color-scheme: light`).

## Производительность

- Слой держится в бюджете: `css/one.css` ≈ 84 КБ из 90, `js/one.js` ≈ 15 КБ из 20
  (пин — `tests/design_layer_test.py`).
- Главная: 39 запросов, ~41 КБ передано сверх кэша (шрифты и бандл — из кэша).
- Тяжёлые списки уже переведены на постраничность в SQL (A4): витрина и «Мои
  кандидаты» — по 24 записи на страницу, возраст и проверка владельца в запросе.
- Уважение к `prefers-reduced-motion` — в слое (`@media (prefers-reduced-motion:
  reduce)` в конце `one.css`) и ранний выход в `one.js`.
